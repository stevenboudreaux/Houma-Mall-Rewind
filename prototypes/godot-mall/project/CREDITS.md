# Credits (third-party assets in the Godot mall)

Started by workstream CHAR-BUILD (Nov 8 2026) because the game had no credits list yet. Every
third-party asset that ships in the game gets a line here; a credits screen in the menu can read this
file. Licences that require a notice carry it in full.

## People (the cast)

**Microsoft Rocketbox Avatar Library** — the cast's bodies, faces, textures and hair
(github.com/microsoft/Microsoft-Rocketbox, commit 0943055d), converted and repainted for this game
(`tools/blender/cast/rocketbox/`, `design/godot-cast.md`).
