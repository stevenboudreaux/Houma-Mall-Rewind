# Scanned materials used by pocket_pal_a (all CC0 1.0, public domain)

Downloaded Nov 10, 2026 from ambientCG (https://ambientcg.com, "all assets are CC0": https://docs.ambientcg.com/license/),
the 1K-JPG sets. Only the maps the build reads are kept here.

| Asset | Page | Maps kept | Used for |
|---|---|---|---|
| Plastic 004 | https://ambientcg.com/a/Plastic004 | Displacement, Roughness | the charcoal case grain |
| Plastic 012 A | https://ambientcg.com/a/Plastic012A | Displacement, Roughness | the light bezel's finer grain |
| Rubber 004 | https://ambientcg.com/a/Rubber004 | Displacement, Roughness | the rubber keys and feet |
| Fingerprints 009 | https://ambientcg.com/a/Fingerprints009 | Opacity | faint smudges in the roughness |

Poly Haven (https://polyhaven.com, also CC0) was checked: it has no moulded-plastic or key-rubber scan (its
"rubber" entries are floor tiles), so nothing from it is used.
No colour map is used: every colour is set in device.py.
